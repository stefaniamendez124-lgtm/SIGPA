# SIGPA

SIGPA es una aplicación de gestión académica y de proyectos. El repositorio
contiene actualmente un frontend React/Vite, una API ASP.NET Core y scripts
SQL para Supabase/PostgreSQL.

La arquitectura objetivo, el modelo relacional, las reglas de integridad, la
matriz RBAC y el contrato REST propuesto están documentados en
[docs/ARQUITECTURA_SIGPA.md](./docs/ARQUITECTURA_SIGPA.md).
